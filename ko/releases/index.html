DeepSRT for Mac 각 버전의 변경 사항, 최신순.

  • 1.5.1최신2026년 8월 10일
    자막 버그 수정: YouTube가 단순히 "zh"(대개 간체자)로 표시한 네이티브 자막 트랙이 번체자 선호와 완전히 일치하는 것으로 잘못 판단되어 번역이 건너뛰어졌습니다. 그 결과 번체자를 설정한 사용자에게 간체자 자막이 표시되던 문제입니다.
  • 1.5.02026년 8월 9일
    DeepSRT PRO: 앱 이름이 제품군(PRO, Mobile, News)에 맞춰 새로 명명되었습니다. 자막 스타일 설정, 실질적인 기록 패널, 클릭 시 자막이 알아서 비켜나는 기능, 다국어 오류 메시지가 추가되었습니다. 노트 읽기.
  • 1.4.12026년 8월 9일
    같은 날 1.5.0으로 대체되었습니다 — 이름 변경과 네 가지 신규 기능은 패치 버전의 범위를 넘어섰습니다.
  • 1.4.02026년 8월 8일
    자막이 전혀 없는 영상을 위한 AI 자동 자막 생성 기능 추가 — 선택적 활성화, 세 번 대신 한 번의 처리로 완료, 잘못된 시간 구간에서도 복구 가능. 노트 읽기.
  • 1.3.02026년 8월 7일
    내장 MCP 엔드포인트 추가: 검색, 자막, 요약, 채널 목록, 영상 정보, 앱에서 열기 등 6가지 도구로 AI 에이전트와 CLI가 시청 중인 콘텐츠를 다룰 수 있습니다 — 본인의 API 키를 사용하며 모든 것이 Mac 안에 머뭅니다. 노트 읽기.
  • 1.2.02026년 8월 5일
    유니버설 바이너리(Apple 실리콘 + Intel), 작업 단위 AI 공급자로 커스텀 OpenAI 호환 엔드포인트 추가(OpenCode Zen, OpenRouter, DeepSeek 프리셋 내장), 작업 단위 Gemini 모델 선택, 번체 중국어를 대만·홍콩 두 가지로 세분화.
  • 1.1.02026년 8월 4일
    무료 Safari 확장 프로그램이 Mac App Store에 출시: 우클릭 메뉴의 "DeepSRT에서 재생"과 재생 위치를 이어받는 툴바 연동. 앱 내 UI가 콘텐츠 언어 설정을 따르도록 개선되었으며, 지원 언어는 7개로 확대.
  • 1.0.12026년 8월 4일
    요약과 자막 패널이 영상 오른쪽에 기본으로 표시됩니다.
  • 1.0.02026년 7월 31일
    Mac App Store 첫 출시. 본인의 Gemini API 키로 YouTube 영상의 AI 요약과 클릭 가능한 자막을 제공하며, 이중 언어 자막의 동기화를 유지하는 "스파인+주석" 아키텍처를 적용했습니다. 노트 읽기.
