원하는 스타일의 요약

빠르게 읽는 서술형 문단, 또는 모든 포인트에 타임스탬프가 붙는 구조화된 불릿 다이제스트. 요약은 한국어, English, 日本語, 繁體中文 등 원하는 언어로 제공됩니다.

깔끔하고 클릭 가능한 스크립트

읽기 좋게 구분된 전체 스크립트. 타임스탬프를 클릭하면 영상이 바로 그 순간으로 이동하고, 클릭 한 번으로 전체를 SRT 파일로 복사할 수 있습니다.

앱에서 바로 시청

내장 YouTube 플레이어가 요약과 스크립트 위에 있습니다. 다이제스트를 읽다가 흥미로운 포인트의 타임스탬프를 클릭하면 영상이 그곳으로 이동합니다.

나의 키, 나의 할당량

나만의 Gemini API 키를 사용하세요. Google AI Studio 무료 등급이면 일상 사용에 충분합니다. 키는 macOS 키체인에만 저장되며 Google 직접 호출에만 사용됩니다.

프라이버시 중심 설계

DeepSRT 서버 없음, 계정 불필요, 분석 추적 없음. 자막은 YouTube에서 Mac으로 직접, 요약은 Mac에서 Google로 직접 전송됩니다. 중간에는 아무것도 없습니다.

무료 Chrome 확장 프로그램

YouTube를 둘러보는 중이라면? 무료 DeepSRT 확장 프로그램이 브라우저 사이드 패널에 동일한 요약과 스크립트를 표시합니다. 백그라운드에서 조용히 실행되는 Mac 앱이 모든 것을 처리합니다.

DeepSRT 구입

Gemini 키 추가

Google AI Studio에서 무료 API 키를 발급받아 설정에 붙여넣으세요. 키체인에 보관됩니다.

3

링크 붙여넣기

YouTube URL을 붙여넣거나 Chrome에서 사이드 패널을 여세요. 요약, 스크립트, 플레이어가 함께 나타납니다.

자주 묻는 질문

내 API 키가 필요한가요?

네. DeepSRT는 나만의 Google Gemini API 키로 작동하며, Google AI Studio에서 무료로 만들 수 있습니다. 키가 본인 소유이므로 DeepSRT에 사용료를 낼 필요도, 월간 AI 구독도 없으며 요청은 Google로 직접 전송됩니다.

DeepSRT는 구독제인가요?

아니요. Mac App Store에서 한 번만 구입하면 됩니다. Chrome 확장 프로그램은 무료입니다.

시청 데이터가 DeepSRT 서버를 거치나요?

절대 아닙니다. DeepSRT 서버 자체가 없습니다. 앱은 YouTube에서 자막을 직접 가져오고, 내 키로 Google Gemini API에 직접 전송합니다. 계정 없음, 추적 없음, 중개자 없음.

어떤 언어를 지원하나요?

요약과 제목 번역은 한국어, 繁體中文, 简体中文, English, 日本語, Español, Français, ไทย를 지원합니다. 스크립트는 영상에 제공되는 자막 언어를 따릅니다.

Chrome이 꼭 필요한가요?

아니요. Mac 앱은 완전히 독립적으로 작동합니다. 링크를 붙여넣으면 요약, 스크립트, 내장 플레이어를 바로 사용할 수 있습니다. Chrome 확장 프로그램은 시청하면서 사이드 패널로 요약을 읽고 싶은 분들을 위한 선택 사항입니다.

DeepSRT v1은 어떻게 되었나요?

v1은 클라우드에서 실행되었습니다. v2는 처음부터 다시 만들어 모든 것을 Mac 위로 옮겼습니다. 더 빠르고, 더 프라이빗하며, 공유 인프라에 의존하지 않습니다. 확장 프로그램은 그대로입니다 — 이제 클라우드 대신 앱과 통신할 뿐입니다.

언제 출시되나요?

DeepSRT v2는 마무리 단계이며 곧 Mac App Store에 출시됩니다. 메일을 보내주시면 출시 시 알려드립니다.
