App 經濟來到關鍵拐點

當人人都寫得出 App，信譽和敘事能力，成了使用者唯一無法自己 vibe 出來的東西。

2026 年 8 月 · DeepSRT 開發筆記

過去一年做 DeepSRT 的過程中，我越來越確定一件事：App 經濟正在經過一個拐點，而且大多數人還沒意識到它的形狀。幾個看法，寫下來存證。

會寫 App 的人，突然變成了所有人

任何人，用 claude-fable-5 或 gpt-5.6-sol 這個等級的 frontier model，都寫得出能跑的 App。不是玩具，是能跑、能上架、能收費的 App。這句話放在兩年前是笑話，放在今天是常識。

接下來就是字面意義上的百花齊放：Apple Developer Program 那張 $99 的門票，是整條路上唯一剩下的門檻。願意繳，就能提交。App Store 即將迎來的供給量，會讓過去所有「獨立開發者的黃金年代」看起來像熱身。

當人人都能寫，App 的價值就不在 App 裡了

這是拐點真正的形狀：當功能本身人人可複製，功能就不再是價值的所在。價值搬家了——搬到開發者身上。

過去的獨立開發者可以完全不理社群：上架一個 $0.99 的 App，然後消失。這條路正在關閉。接下來的開發者會在 Threads、X、LinkedIn 上持續分享進展，寫開發筆記闡述觀點，開 GitHub 讓人追蹤進度，經營 Discord 跟使用者站在一起。不是因為行銷課這樣教，而是因為信譽和敘事能力，成了使用者唯一無法自己 vibe 出來的東西。

告別銅板價

所以好 App 的價格不會再是 $2.99。我認為健康的買斷價會落在 $50–$100 之間。

不妨想一想：你花 $2.99 甚至 $0.99 買斷的產品出了問題，你在 Threads 上抱怨，甚至寫 email 給開發者——你真的認為他們會認真花時間幫你處理嗎？不是他們冷漠，是這個價格根本供養不起那份認真。如果你得不到客服、甚至無法和開發者直接對話提交產品建議，那麼銅板價的 App，並不足以支撐這個由 AI 開發驅動的新 App 經濟。

這個數字不是功能的標價——功能很便宜，上面說過了。它是長期承諾的標價。寫出 code 是一個週末的事；接下來的迭代、相容性維護、回覆使用者、修那些只在特定機器上出現的 bug——這場馬拉松才是艱辛的部分。$50 買的不是今天的 App，是這個團隊會陪你跑完馬拉松的信號。

「自己 Vibe 不划算」的甜蜜點

這個價位有個精確的定義：它會落在你自己 vibe 完全不划算的位置。

它不便宜。而且說實話，你自己也寫得出來——這正是它微妙的地方。但當你真的動手，賠掉好幾個週末、燒掉自己的 token 額度去修那些邊角案例之後，你會得出跟所有人一樣的結論：不划算。時間不划算，token 不划算，最不划算的是你得一直維護它。

買斷一個有人承諾維護的版本，突然變成理性選擇。這在 $0.99 的時代是不成立的——那時候 App 便宜到你不會想自己寫；在新時代它重新成立，因為 App 貴到值得你想一下，然後想清楚。

真正的稀缺：品味，和「意識到」

最後，也是我認為最重要的一點：產品的價值從來不在「寫出來」這個動作裡。它在品味裡——在你意識到「原來可以這樣做」而別人根本沒想到的那一刻裡。

模型可以替你寫任何你描述得出來的東西。但「描述得出來」本身就是門檻：知道該做什麼、知道什麼不該做、知道使用者還沒說出口的需求長什麼樣子。這是價值。這一直都是價值——只是過去它被「會不會寫 code」的門檻擋住，現在門檻沒了，它終於裸露出來。

把它寫出來

所以，如果你心裡有一個產品——那個你想了好幾年、每次看到類似的東西都覺得「不對，不是這樣」的產品——現在就是把它寫出來的時候。門票 $99，工具在你手上，剩下的只有你的品味和你願不願意跑馬拉松。

而且這條價格曲線還有繼續向上的理由：高階模型的開發成本正在水漲船高。好的 App 值得更好的買斷定價——而你的每一次購買，其實就是在支持這個開發者或團隊，支持他們持續用 AI 去維護、去創作更好的產品。

寫出來，然後持之以恆地維護它。後半句才是產品。
