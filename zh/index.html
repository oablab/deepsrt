常見問題

我需要自己的 API 金鑰嗎？

是的——DeepSRT 使用你自己的 Google Gemini API 金鑰，可以在 Google AI Studio 免費申請。因為金鑰是你的，不用付 DeepSRT 任何使用費、沒有每月 AI 訂閱，請求也直接送到 Google。

DeepSRT 是訂閱制嗎？

不是。DeepSRT 在 Mac App Store 上買斷一次，Chrome 擴充功能免費。

我的觀看資料會經過 DeepSRT 的伺服器嗎？

絕對不會——根本沒有 DeepSRT 伺服器。App 直接從 YouTube 抓字幕、用你的金鑰直接把逐字稿送到 Google Gemini API。不需帳號、沒有分析追蹤、沒有中間人。

支援哪些語言？

摘要與標題翻譯支援繁體中文、简体中文、English、日本語、한국어、Español、Français、ไทย。逐字稿則依影片本身提供的字幕語言而定。

一定要用 Chrome 嗎？

不用。Mac App 完全獨立運作——貼上連結就有摘要、逐字稿和內建播放器。Chrome 擴充功能是選配，給喜歡邊看影片邊在瀏覽器側邊面板讀摘要的人。

DeepSRT v1 怎麼了？

v1 跑在雲端。v2 是從零重寫，把一切搬到你的 Mac 上：更快、更私密、不再依賴共用基礎設施。擴充功能還在——只是現在連的是 App，不是雲端。
