リリース

DeepSRT for Mac の各バージョンの内容。新しい順。

  • 1.5.1最新2026年8月10日
    字幕の不具合を修正:YouTube が単純な「zh」（多くは簡体字）とラベル付けしたネイティブ字幕トラックが、繁体字中国語の設定と完全一致とみなされてしまい、翻訳がスキップされていました。繁体字を指定したユーザーに簡体字の字幕が表示される問題です。
  • 1.5.02026年8月9日
    DeepSRT PRO:アプリ名がプロダクトファミリー（PRO、Mobile、News）に合わせて刷新されました。字幕スタイル設定、本格的な履歴パネル、クリックで字幕が自動的に避ける機能、多言語対応のエラーメッセージを追加。ノートを読む。
  • 1.4.12026年8月9日
    同日に 1.5.0 へ引き継がれました──名称変更に加え4つの新機能は、パッチバージョンの範囲を超えていました。
  • 1.4.02026年8月8日
    字幕が全くない動画向けの AI 文字起こし機能を追加──オプトイン、1回の取り込みで完結（従来は3回）、時間ウィンドウの失敗にも復帰できます。ノートを読む。
  • 1.3.02026年8月7日
    MCP エンドポイントを内蔵:検索・文字起こし・要約・チャンネル一覧・動画情報・アプリ内で開く、の6つのツールで、AI エージェントや CLI が視聴中のコンテンツを操作できます──自分の API キーを使い、すべてが Mac 内に留まります。ノートを読む。
  • 1.2.02026年8月5日
    ユニバーサルバイナリ（Apple silicon + Intel）、カスタム OpenAI 互換エンドポイントをタスク単位の AI プロバイダとして追加（OpenCode Zen、OpenRouter、DeepSeek のプリセット内蔵）、タスク単位の Gemini モデル選択、繁体字中国語を台湾・香港の2種類に分割。
  • 1.1.02026年8月4日
    無料の Safari 拡張機能が Mac App Store に登場:右クリックメニューの「DeepSRT で再生」と、再生位置を引き継ぐツールバー連携。アプリ内 UI がコンテンツ言語設定に追従するようになり、対応言語は7言語に。
  • 1.0.12026年8月4日
    要約と文字起こしのパネルが動画の右側に表示されるようになりました（デフォルト）。
  • 1.0.02026年7月31日
    Mac App Store で最初のリリース。自分の Gemini API キーで YouTube 動画の AI 要約とクリック可能な文字起こしを提供し、バイリンガル字幕の同期を保つ「スパイン＋アノテーション」アーキテクチャを採用。ノートを読む。
